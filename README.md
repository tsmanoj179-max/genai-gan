# Generative AI for Image Synthesis Using GANs

This project has two goals:

1. Generate synthetic images with a GAN.
2. Classify an uploaded image as `real` or `fake` / AI-generated.

It is designed for a CPU-only laptop such as an Intel i7-13620H with 16 GB RAM. The default settings use 128x128 images, small batch sizes, and zero DataLoader workers so the scripts also run smoothly from Spyder and Anaconda Prompt on Windows.

## Why This GAN

For a CPU-only system, the best practical GAN choice is a compact DCGAN-style model. Larger GANs such as StyleGAN are stronger in research settings but are not realistic to train from scratch on 60k images without a GPU. This project therefore uses:

- `DCGAN` as the required GAN method for image synthesis.
- `ConvVAE` as a second non-GAN image synthesis method.
- `MiniCNN` as the real/fake classifier.

## Folder Structure

Place your original dataset here:

```text
data/
  raw/
    real/        put your 30k real images here
    fake/        put your 30k fake or AI-generated images here
  processed/    generated by preprocessing; leave empty first
  splits/       train/val/test csv files; generated by preprocessing
models/
  classifier/   trained classifier checkpoints
  gan/          trained GAN checkpoints
  vae/          trained VAE checkpoints
outputs/
  samples/      generated images and sample grids
  reports/      training metrics and summaries
src/
  app.py        Streamlit page for generate + classify
  train_gan.py
  train_vae.py
  train_classifier.py
  generate_image.py
  infer_classifier.py
```

If your dataset is already in root-level `real/` and `fake/` folders, you can keep it there and pass those paths to the preprocessing script.

## Running the Application (Windows Desktop or Web App)

If you encounter `ModuleNotFoundError: No module named 'torch'`, simply double-click **`Install_Dependencies.bat`** first, or activate your Anaconda environment (`conda activate gan-image-project`).

You can run this project in **3 convenient ways**:

1. **Native Windows Desktop Application (GUI Window)**:
   - Double-click `Launch_Windows_Desktop_App.bat`, or run:
     ```powershell
     python src/desktop_app.py
     ```
   - Opens a native desktop window with tabs for image generation (GAN & VAE), deepfake image classification, and model health.

2. **Web Application (Streamlit in Browser)**:
   - Double-click `Launch_Web_App.bat`, or run:
     ```powershell
     streamlit run src/app.py
     ```
   - Opens in your favorite web browser at `http://localhost:8501`.

3. **Dedicated Desktop Window Mode (Frameless Web App Window)**:
   - Double-click `Launch_App_Window_Mode.bat`.
   - Runs the rich web application inside a dedicated standalone desktop application window (no address bar or browser tabs).

## Recommended Workflow

### 1. Prepare the dataset

This resizes all images to a consistent square size and creates train/validation/test splits.

```powershell
python -m src.data.prepare_dataset --real-dir data/raw/real --fake-dir data/raw/fake --image-size 128
```

For an easier first run on CPU, use 64:

```powershell
python -m src.data.prepare_dataset --real-dir data/raw/real --fake-dir data/raw/fake --image-size 64
```

### 2. Train the classifier

```powershell
python -m src.train_classifier --epochs 8 --batch-size 32 --image-size 128
```

If the laptop becomes slow:

```powershell
python -m src.train_classifier --epochs 5 --batch-size 16 --image-size 64
```

### 3. Train the GAN

The GAN trains on real images only, because its job is to learn the real-image distribution and synthesize new images.

```powershell
python -m src.train_gan --epochs 20 --batch-size 16 --image-size 128
```

CPU GAN training can take a long time. Start with 64x64 for quick testing:

```powershell
python -m src.train_gan --epochs 5 --batch-size 16 --image-size 64
```

### 4. Train the VAE synthesis model

```powershell
python -m src.train_vae --epochs 10 --batch-size 16 --image-size 128
```

### 5. Evaluate the classifier

```powershell
python -m src.evaluate_classifier
```

### 6. Run the web page

```powershell
streamlit run src/app.py
```

The app has two tabs:

- Generate Image: GAN or VAE image synthesis.
- Classify Image: upload an image and predict real/fake.

The app will still open before training. Generation uses an untrained model as a placeholder if no checkpoint exists, and classification explains that a classifier checkpoint is needed.

## Spyder Notes

In Spyder, set the working directory to this project folder, then run scripts such as:

```python
%run src/train_classifier.py --epochs 3 --batch-size 16 --image-size 64
```

For long training runs, Anaconda Prompt is usually more reliable than Spyder because it shows progress continuously.
