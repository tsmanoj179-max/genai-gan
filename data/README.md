# Data Allocation

Keep original images separate from processed images.

```text
data/raw/real/      original real images
data/raw/fake/      original fake or AI-generated images
data/processed/     generated by preprocessing; leave empty first
data/splits/        generated csv files; leave empty first
```

Supported image extensions:

- `.jpg`
- `.jpeg`
- `.png`
- `.bmp`
- `.webp`

Run preprocessing before training:

```powershell
python -m src.data.prepare_dataset --real-dir data/raw/real --fake-dir data/raw/fake --image-size 128
```
